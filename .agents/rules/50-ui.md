# UI

- Use the design tokens (`--char`, `--cream`, `--ember`, `--saffron`, `--herb`, `--chilli`, `--smoke`) via Tailwind theme — never raw hex in components. Tokens are overridable from Settings → Branding.
- shadcn/ui components first; extend with variants (`cva`) instead of new components.
- Every interactive element: visible focus, label/aria, ≥ 44 px target (≥ 56 px on `/till` and `/station`).
- Every data view: loading skeleton, empty state with a next action, error state with retry.
- Motion: purposeful only (add-to-cart, status change, ready flash). Respect `prefers-reduced-motion`. No animation on the LCP element.
- Kitchen screens: dark theme, huge type for item names, colour + icon (never colour alone) for urgency and allergies.
- Prices: `formatAUD(cents)` from `lib/money.ts`, tabular numerals.
- Copy: Australian English, friendly and short ("Your order's ready, mate" style is fine on the website; plain on staff screens).
- Never copy Domino's/KFC logos, images, wording or distinctive layouts — learn patterns, create original work.
